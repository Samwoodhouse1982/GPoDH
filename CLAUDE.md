## Taking over this project?

Read **`HANDOFF.md`** in the repo root first — it is the complete operating
manual: architecture, data model, CMS, video sync, search, secrets registry,
deployment, known blockers, and the outstanding TODO list. Then skim
`src/lib/episodes.ts`, `src/lib/videos.ts`, and `src/app/globals.css`, and run
`npm run build` to confirm a clean baseline before changing anything.
